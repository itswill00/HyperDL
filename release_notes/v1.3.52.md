# HyperDL v1.3.52

> **b13520** · full-zip release · changes since `v1.3.51`

Bundles the full FFmpeg shared-library closure so audio downloads work on phones without Termux, detects broken media tools honestly, and fails fast with clear errors instead of cryptic logs.

---

## Highlights

| Area | What changed |
| :--- | :--- |
| **Audio fix** | FFmpeg and its library closure ship inside the module, so extraction works on clean devices |
| **Detection** | Health check probes the real binaries instead of trusting the executable bit |
| **Errors** | Audio fails fast with an actionable message when the toolchain is broken |
| **Packaging** | Broken media runtimes are rejected at build time, never shipped |

---

## Fixed audio on Termux-free phones

- **Bundled the full media closure.** `ffmpeg` and `ffprobe` now ship with every shared library they need, because the old build only worked where Termux happened to be installed.
- **Patched all runpaths.** Every binary and library points at relative locations, so nothing references Termux paths at runtime.
- **System libraries load first.** Platform libraries always resolve to the system copy, because bundled copies shadowed them and broke linking on stock devices.

## Honest media-tool detection

- **Probe runs the real binary.** Detection executes `-version` instead of checking the executable bit, because a present-but-broken binary lied to the health screen.
- **Audio fails fast.** Extraction checks for working `ffmpeg`/`ffprobe` before starting `yt-dlp`, because a mid-run failure only produced cryptic logs.
- **Clearer messages.** Toolchain failures now name the cause and the remedy (`reboot, then try again`) instead of dumping raw `yt-dlp` stderr.

## Strict packaging gate

- **Broken builds are rejected.** Packaging requires the media binaries plus their `libav` closure, because an incomplete runtime previously passed verification and shipped.
- **Covered by tests.** Detection, error mapping, environment ordering, and audio fail-fast all have unit tests, so regressions break the build instead of users.
