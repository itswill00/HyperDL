# HyperDL v1.3.49

> **b13490** · full-zip release · changes since `v1.3.48`

Closes a root shell-injection path in media scanning, fixes stale resume files being marked complete, makes status writes crash-safe, and polishes the WebUI for offline use and small screens.

---

## Highlights

| Area | What changed |
| :--- | :--- |
| **Security** | Shell-free media scan and file open paths, hardened query escaping |
| **Reliability** | Signed-URL resume failures restart clean instead of faking success |
| **Stability** | Atomic status writes and bundled library path fix for ffmpeg |
| **WebUI** | Correct language label, offline button state, focus-leak fix, compact search bar |

---

## Security hardening

- **Shell-free media scan.** `scan_media_file` now spawns `am` and `content` directly without a shell, so remote video titles can never break out into a root shell.
- **Shell-free file actions.** Delete and open paths in the native bridge now use detached exec instead of `system()`, with percent-encoded file URIs.
- **Hardened media query.** The `content query` fallback escapes quotes, backslashes, dollars, and backticks in addition to single-quote doubling, because filenames come from remote titles.
- **Clipboard status is JSON-safe.** The daemon escapes backslashes and quotes before writing clipboard URLs into status JSON, so a crafted link cannot corrupt polling.

## Download reliability

- **Clean restart on HTTP 416.** The direct downloader now purges the stale partial and retries once from the start when a signed URL expires, instead of promoting a truncated file as complete.
- **Atomic status files.** The bridge and the daemon now write status through `.tmp` plus rename, so a crash mid-write never leaves truncated JSON for the WebUI.
- **Bundled libraries for ffmpeg.** The runtime wrapper now includes `runtime/lib` in `LD_LIBRARY_PATH`, so the bundled `ffmpeg` finds its own `libz` and `libssl` builds.

## WebUI polish

- **Correct language label.** The subtitle chip now reads Indonesian instead of Indonesia, matching the English language name.
- **Offline button state.** The download button gets a real `btn-offline` style instead of silently falling back to the primary color.
- **Focus listener fixed.** The window `focus` handler is now a named function, so it unregisters cleanly instead of leaking.
- **Compact search bar.** The history search input now carries `min-width: 0; width: 100%` with `overflow: hidden` on the wrapper, keeping the clear button on-screen.
- **Safer navigation.** The Instagram notice uses a button instead of a `javascript:` link, avoiding WebUI content-policy blocks.
