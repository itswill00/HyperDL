# HyperDL v1.3.50

> **b13500** · full-zip release · changes since `v1.3.49`

Makes the console activity log readable at a glance with color-coded rows, level filters, and a follow toggle, plus a slimmer header and slimmer clipboard banner.

---

## Highlights

| Area | What changed |
| :--- | :--- |
| **Console** | Color-coded log rows with All, Errors, Warnings, and Info filters |
| **Layout** | Slimmer sticky header and slimmer clipboard detection banner |
| **Motion** | Specific property transitions instead of catch-all transitions |

---

## Console readability

- **Color-coded rows.** Errors, warnings, success, and info lines now carry their own dot and tint, so a failure stands out without reading the whole wall.
- **Level filters.** All, Errors, Warnings, and Info chips narrow the list to what matters instead of scrolling raw output.
- **Follow toggle.** Auto-scroll to the bottom is now optional, so reading older entries no longer fights live updates.
- **Cleaner text.** Status JSON is shortened to a human line, long URLs wrap on word boundaries, and the list caps at the latest entries.

## Compact layout

- **Slimmer header.** The sticky header drops from 58px to 46px with tighter padding and type, giving content more room.
- **Slimmer clipboard banner.** Smaller padding, type, and buttons keep the detection card neat on narrow screens.
- **Calmer motion.** Checkbox and health rows animate only color and border instead of every property, which stays smooth on older WebViews.
