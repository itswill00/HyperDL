# HyperDL v1.3.53

> **b13530** · full-zip release · changes since `v1.3.52`

TikTok photo posts with background audio now save as a single slideshow video when video format is picked, with tougher Facebook and X extractors behind it.

---

## Highlights

| Area | What changed |
| :--- | :--- |
| **TikTok slideshow** | Photo posts with audio now mux into one MP4 on video requests instead of dropping the track |
| **Facebook** | More stream patterns plus `og:video` fallback catch links the old regexes missed |
| **X / Twitter** | Extra guest mirror keeps video resolution working when one endpoint is rate-limited |

---

## TikTok photo posts finally honor the video format

- **Muxed photo-plus-audio into one MP4.** Video requests on carousels now build a slideshow with `ffmpeg` instead of returning bare JPGs, because users asked for a video and got photos.
- **Kept Photos and Audio honest.** `album` still returns per-slide images and `audio` still returns the background track, because each format should do exactly what its label promises.
- **Fell back safely.** A failed mux drops to the photo album plus the mirror resolver instead of crashing, because an on-device `ffmpeg` is not guaranteed on every setup.

## Tougher Facebook extraction

- **Matched more stream shapes.** Added `hd_src`/`sd_src` patterns next to the existing progressive and native URLs, because Facebook serves different markup per surface.
- **Used `og:video` before giving up.** Video requests now try the embed tag before the generic fallback, because a direct file beats another resolver round-trip.

## Steadier X resolution

- **Added the `vxtwitter` mirror.** Guest resolution now fans out to three endpoints, because a single mirror gets throttled and kills downloads.
