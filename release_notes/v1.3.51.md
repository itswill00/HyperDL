# HyperDL v1.3.51

> **b13510** · full-zip release · changes since `v1.3.48`

Locks down every root shell path, makes resolving visibly faster with live step feedback and background prefetching, overhauls the console log and motion design, and clears a second full audit with zero findings left open.

## Security hardening

- **No shell left in the bridge.** Media scan, file open, removal cleanup, media query, and clipboard reads now use direct process spawning, so remote video titles can never break into a root shell.
- **No shell left in the extractor.** Media scanning spawns its helpers argument by argument instead of through a command string.
- **Crash-safe status files.** Every status write goes through a temporary file plus rename, including the daemon, so a kill mid-write never leaves truncated JSON.
- **Escaped output.** File names and pasted links are escaped before entering JSON, and media queries escape quotes, backslashes, dollars, and backticks.
- **Null-safe parsing.** Social platform responses now survive explicit `null` fields instead of crashing on them.
- **Exact vault matching.** Required domains match whole lines only, so lookalike entries can no longer suppress them.
- **Stricter plumbing.** Daemon liveness uses the same process check everywhere, and utility downloads fail loudly instead of saving error pages as binaries.

## Faster resolving

- **Live step feedback.** TikTok, Instagram, Facebook, and X now report each resolving stage, so the task card keeps moving instead of freezing on one line.
- **Bounded Instagram extractor.** A hung interpreter falls back after 25 seconds instead of stalling without word.
- **Leaner cold start.** Rare-path imports load on demand, cutting roughly 200ms off every fresh process start.
- **Fairer probe scheduling.** Probes run at the same priority as downloads instead of the lowest one.
- **YouTube prefetch.** Pasting a link quietly starts probing in the background, so the resolution sheet often opens with results ready.

## Console and layout

- **Readable activity log.** Color-coded rows for errors, warnings, success, and info, level filter chips, JSON shortened to human lines, and an optional follow toggle.
- **Slimmer chrome.** The sticky header, history rows, action buttons, and clipboard banner all lost padding without losing touch targets.
- **Smarter buttons.** Download stays hidden until a link exists, saving cookies stays disabled until text exists, and update buttons keep a fixed width with fading labels.
- **Correct language label.** The subtitle chip reads Indonesian, and old notes were fixed to match.

## Motion everywhere

- **Smooth reveals.** Buttons rise in, lists cascade, empty states fade, and notices slide down — nothing pops like a jumpscare.
- **Animated dismissal.** Sheets, dialogs, and previews slide and fade closed instead of vanishing.
- **Calmer motion.** Checkbox and health rows animate only color and border, and one-shot animations no longer hold compositor layers.
