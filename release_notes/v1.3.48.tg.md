*HyperDL v1.3.48* (13480)

*Changelog:*
```
• Queue: line up links, downloads run one by one on their own.
• Failed ledger: failures stay visible with Retry + Dismiss.
• Playlist: fetch a series with optional from/to range.
• Subtitles: ID/EN tracks save next to the video.
• Picker cover: video thumbnail shown before you commit.
• Audio: M4A + Opus are real targets now, no more silent MP3 fallback.
• Update check: HyperDL version + notes inside the Console tab.
• Notifications: Normal / Verbose / Silent switch in settings.
• Vault editor: watched domain list with validation on save.
• Safety: open + preview enforce the same folder boundary as delete.
```

*Notes:*
• Requires Android 10+ (arm64).
• Flash via KernelSU, APatch, or Magisk.
