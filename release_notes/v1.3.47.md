# HyperDL v1.3.47

> **b13470** · full-zip release · changes since `v1.3.46`

Reopening a link is now instant. HyperDL remembers which resolutions a video offers, so the wait before the resolution list appears only happens the first time you open that link.

---

## Highlights

| Area | What changed |
| :--- | :--- |
| **Speed** | Reopening a link resolves in under a second instead of about four |
| **Privacy** | The cache stores format lists only, never signed stream links |
| **Footprint** | Capped at 200 entries and self-cleans after six hours |

---

## Speed

- **Resolution results are now cached per link.** Opening the same link again shows the quality list right away instead of waiting for the platform to answer again. On YouTube that wait was the slowest part of starting a download, roughly four seconds on a good connection.
- **Only the choice is remembered, never the file link.** Stream addresses expire quickly, so the download always fetches a fresh one. That keeps the earlier `HTTP 416` fix working exactly as before.
- The cache expires after six hours and keeps at most 200 links, so it never grows without bound and rarely needs clearing.
- First-time links are unaffected. They still resolve once, then land in the cache for next time.

## Privacy

- **The cache holds quality names and sizes only.** It never stores your cookies, your signed media links, or anything tied to your account.
- The cache file is readable only by the system, and removing the module removes the cache with it. Your downloaded files are always left alone.
