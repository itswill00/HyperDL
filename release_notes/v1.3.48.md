# HyperDL v1.3.48

> **b13480** · full-zip release · changes since `v1.3.47`

Download several links in a row without babysitting the app, retry failures where they happened, grab whole playlists and subtitles, check for HyperDL updates without leaving the app, and manage the vault list safely.

---

## Highlights

| Area | What changed |
| :--- | :--- |
| **Queue** | Line up links and let them download one by one |
| **Recovery** | Failed downloads keep a retry button where they failed |
| **Media** | Playlist ranges, subtitle tracks, and cover art in the picker |
| **Control** | In-app update check, notification modes, vault list editor |

---

## Queue and recovery

- **Download queue.** The download card has a Queue button next to Download. Queued links wait their turn and start on their own, so pasting five links no longer means watching the first four finish.
- **Failed ledger.** A failed download now stays visible with its error message, a Retry button that reuses the same format, and Dismiss. Failures survive restarts, so nothing silently disappears.
- Queue and ledger both live on the device only and never leave it.

## Media options

- **Playlists.** Flip the Playlist switch on a series link and optionally set a from/to range. Each item lands as its own file, named and numbered by the platform order.
- **Subtitles.** Video downloads offer None, Indonesian, English, or both. Tracks save alongside the video as separate subtitle files, and the picker tells you which languages a video actually has.
- **Cover art.** The resolution picker now shows the video thumbnail, so you can confirm the right video before committing to a large file.
- **More audio targets.** The console offers M4A and Opus next to MP3 and FLAC. Both are now real download paths instead of silently falling back to MP3.

## Control and safety

- **In-app update check.** The console has a HyperDL update row next to the yt-dlp one. It shows the latest version with its notes and a link, instead of making you check the releases page by hand.
- **Notification modes.** Automation settings offer Normal (milestones), Verbose (every tick), and Silent. Previously these needed hidden flag files.
- **Vault list editor.** The vault tab now shows the watched domain list with a count, and saving validates every line. Bad lines are skipped instead of breaking routing.
- **Tighter file access.** Opening and previewing now enforce the same folder boundary as deletion, and the audio format setting rejects anything outside the four supported targets.
