# HyperDL v1.3.45

> **b13450** · full-zip release · changes since `v1.3.42`

Fixes YouTube downloads that failed with `HTTP 416`, stops release packaging from quietly filling up your phone's shared storage, and rebuilds the documentation around actual usage.

---

## Highlights

| Area | What changed |
| :--- | :--- |
| **YouTube** | Resumed downloads no longer die with `HTTP Error 416` |
| **Storage** | Release zips stay in internal builds, never copied to `/sdcard` |
| **Docs** | README rebuilt with usage, configuration, troubleshooting, and FAQ |

---

## YouTube downloads

- **Fixed `HTTP Error 416: Requested range not satisfiable`** on resumed downloads. YouTube hands out short-lived signed links, so a resumed request frequently asked for a byte range past the end of the newly issued file. YouTube now keeps its own temporary file instead of forcing resume flags.
- **Automatic recovery.** If a range error still occurs, the stale partial is cleared and the download retries once from the start, so you never have to restart a job by hand.
- **Resume still works.** Interrupted downloads continue from where they stopped, and the retry stays invisible unless it is actually needed.

## Build & docs

- **No more shared-storage copies.** Release zips are no longer mirrored to `/sdcard`; internal builds land in `releases/` only. Packaging stopped quietly eating into your free space.
- **README rebuilt** with a table of contents, step-by-step usage, a configuration reference for cookies, audio format, the private vault, and the clipboard watcher, plus troubleshooting and FAQ sections covering the most common download failures.

## Distribution

- **Releases now live in this repository.** Download from the [Releases page](https://github.com/itswill00/HyperDL/releases).
- The separate `HyperDL-Release` repo is kept as an archive for versions up to `v1.3.42`.
