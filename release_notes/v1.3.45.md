HyperDL v1.3.45 (b13450) — full-zip release. Changes since v1.3.42:

YouTube downloads
- Fixed "HTTP Error 416: Requested range not satisfiable" that hit resumed YouTube downloads. YouTube hands out short-lived signed links, so a resumed request often asked for a range past the end of the newly issued file.
- YouTube now lets the downloader keep its own temporary file instead of forcing resume flags, and any range error is retried once from the start after clearing the stale partial.
- Interrupted downloads still resume as before, and the retry stays invisible unless it is actually needed.

Build & docs
- Release zips are no longer copied to shared storage. Internal builds land in releases/ only, so packaging stops quietly eating into your phone's free space.
- README rewritten with a table of contents, step-by-step usage, a configuration reference for cookies, audio format, the private vault, and the clipboard watcher, plus troubleshooting and FAQ sections covering the most common download failures.
- Releases now live in this repository. The separate HyperDL-Release repo is kept as an archive for older versions.
